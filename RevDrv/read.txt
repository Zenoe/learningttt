RevDrv is a WFP bind/source-IP forcing demo.

Goal:
Control a specific process ID and force sockets that bind to INADDR_ANY
(0.0.0.0) to bind to the vNIC IP, for example 10.8.0.4.

Current model:
1. User mode sends a root PID, box name, and vNIC IP to the kernel driver.
2. RevDrv keeps a fixed-size PID table and inherits child PIDs in kernel via
   PsSetCreateProcessNotifyRoutineEx.
3. RevDrv registers only FWPM_LAYER_ALE_BIND_REDIRECT_V4.
4. For tracked PIDs, localAddressAndPort is changed from 0.0.0.0 to the vNIC
   IP when the process actually binds a socket.
5. For non-target PIDs that explicitly bind the vNIC IP, localAddressAndPort
   is reset to 0.0.0.0 so normal route/interface selection applies.

Route requirement:
Add a low-priority default route to the vNIC so the socket layer considers it
routable, while normal traffic still prefers the real default route.

Example:
route add 0.0.0.0 mask 0.0.0.0 10.8.0.4 metric 9999
